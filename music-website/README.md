# Music Website

## 構成
- GitHub Pages: HTML/CSS/JavaScriptの公開
- Google Apps Script: 公演情報の取得、予約、問い合わせ
- Google Sheets: データ保存

## 初期設定
1. Googleスプレッドシートを作り、IDを控える。
2. GASプロジェクトを作成し、`gas/Code.gs` の内容を貼り付ける。
3. GASの「プロジェクトの設定」→「スクリプト プロパティ」に `SPREADSHEET_ID` を登録する。
4. `ADMIN_EMAIL` に問い合わせ通知先メールアドレスを登録する（任意）。
5. `setupSheets` を一度実行し、権限を承認する。
6. GASをウェブアプリとしてデプロイし、アクセスできるユーザーを「全員」に設定する。
7. 発行されたウェブアプリURLを `app.js` の `GAS_WEB_APP_URL` に設定する。
8. GitHubリポジトリにHTML/CSS/JavaScriptファイルを登録し、GitHub Pagesを有効にする。

## 注意
- `Concert` シートの `status` が `open` の公演だけ公開一覧に表示されます。
- 公演データは1行目の見出しに対応する列へ入力してください。
- GASの実行権限・メール送信権限を確認してください。
- この初期版には管理者ログイン・公演編集・受付機能はまだ実装していません。公開前に管理者機能、スパム対策、個人情報保護、予約の同時処理テストを追加してください。
- GASのロックは同一GASプロジェクト内の処理を直列化しますが、予約の完全なトランザクションを保証するものではありません。
